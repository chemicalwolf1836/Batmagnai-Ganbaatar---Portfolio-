Neon Kissa V2

A redesigned bilingual cocktail bar website built on Next.js and React 19, featuring four switchable neon palettes, a mood-based cocktail finder, an AI virtual host, and a reservation workflow.

At a glance

Overview

Project Summary

Neon Kissa V2 is a fully separate redesign of the original Tokyo Neon Kissa concept. Built as a standalone Next.js app with React 19, it expands on V1 with a four-palette colour system, a more interactive cocktail finder, and a bilingual virtual host named Hana.

Stack

Stack & Architecture

  • Next.js 16 — App Router, static export
  • React 19 — client components, hooks
  • TypeScript 5 — full type coverage
  • Tailwind CSS v4 — utility-first styling
  • CSS custom properties — live palette switching
  • next/font/google — Zen Kaku Gothic New + Space Mono
  • Vercel — deployment
Features

Key Features

  • Four neon palettes — Ruby, Cyber, Amber, and Jade, switched live via CSS custom properties on the root element
  • Bilingual UI — English and Japanese with localStorage persistence across page loads
  • Cocktail finder — mood and sweetness scoring algorithm that ranks all four menu items in real time as the user changes filters
  • Hana AI chat — rule-based virtual host with bilingual responses for common questions about hours, access, menu, and reservations
  • Reservation form — multi-field booking request with a confirmation state
  • Atmosphere mosaic — CSS Grid photo layout with 7 tiles, some spanning multiple columns and rows
  • Daily hero image — rotating Unsplash photos chosen by day of the week
Challenges

Challenges & Learnings

  • Palette system — managing four accent colours plus secondary and text variants cleanly using a single CSS custom property swap on the root element
  • Bilingual content at scale — organising EN/JP strings for an entire page, including chip labels, form fields, and chatbot responses, without duplication
  • Scoring algorithm — implementing a live-updating cocktail ranking that handles flavour keyword matching, sweetness penalties, and avoid-list deductions
  • Tailwind v4 syntax — adapting to the new import-based config and CSS-first approach instead of a JS config file

Problem

The original Tokyo Neon Kissa was a solid first version, but I wanted to explore how far I could push the same concept — more visual personality, a stronger design system, and a more interactive cocktail discovery experience. I also wanted to practice building a fully separate project from scratch using a new design as a starting point.

Solution

I converted a Claude Design prototype into a Next.js app with React 19, then built out all the interactive features — palette switching, bilingual state, the cocktail finder scoring system, and the Hana chatbot — as a single client component. The four-palette system uses CSS custom properties so any colour switch is instant with no JavaScript DOM manipulation beyond toggling a data attribute.

How I Built It

A closer look at the implementation behind the main features.

Design

Palette System

Defined four named palettes (Ruby, Cyber, Amber, Jade) as CSS custom property overrides using [data-palette="..."] selectors. A single setAttribute call on the HTML element swaps all accent colours simultaneously with no JavaScript DOM walking.

Logic

Cocktail Finder

Scored each drink item in real time: +3 for a mood match, +2 for sweetness, +1–2 per matching flavour keyword in the likes field, and -5 for each term found in the avoid field. The best match updates live as the user types, with no submit button required.

Frontend

Hana Chatbot

Built as a rule-based responder using regex pattern matching against common questions about hours, location, menu, reservations, and payment. Responses are bilingual — the bot reads the current language state and replies in the same language the user typed in.

Result

This project deepened my understanding of CSS-driven theming, TypeScript component design, and client-side state management with React hooks. Building V2 as a fully separate project — rather than patching V1 — taught me the value of starting clean when the design direction changes significantly.
