BJT Trainer

An offline-first Japanese vocabulary trainer for the Business Japanese Proficiency Test - audio-first recall, Leitner spaced repetition, and an installable PWA that works on a train with no signal.

Live Demo ↗ Source ↗ ← Back
Overview

Project Summary

BJT Trainer is a personal study tool I use daily and built as a portfolio piece. It plays a Japanese word or phrase, you produce the reading and meaning from memory, then reveal and grade yourself. The whole app runs with no network - vocabulary is bundled in and audio comes from the browser's own speech engine - so it keeps working on the commute where there is no signal.

Stack

Stack & Architecture

  • Next.js 16 - App Router, static export (no server at runtime)
  • TypeScript - strict mode throughout
  • Tailwind CSS - styling system
  • Web Speech API - native SpeechSynthesis for Japanese audio, no audio files
  • Vitest - 136 unit tests over the pure logic core
  • Service Worker - hand-written, cache-first offline shell
  • Vercel - deployment
Modes

Practice Modes

  • Vocabulary recall - audio plays, you recall the reading and meaning, then reveal and self-grade; typing the reading is optional
  • First-exposure step - a word you have never seen introduces itself with text before it is ever quizzed blind by ear
  • Business phrases - a deck of keigo and workplace set-phrases using the same flow
  • Unit browser - all 24 themed weeks, each with its own progress, drill a single week at a time
  • Shadowing mode - a full sentence plays, then a timed beat gives you space to repeat it aloud
Progress

Scheduling & Goals

  • Leitner boxes - a correct answer promotes a card one box, a miss sends it back to box 1, so weak cards surface first
  • No calendar - the next unit unlocks when 75% of the previous one is learned, so pace follows how much you actually study rather than a fixed schedule
  • Unit unlock ring - on the study screen, a countdown to the next unit that reads toward the unlock point, not the whole unit
  • Course mastery bar - on the home screen, every card tracked from box 1 to box 5, plus an honest pace estimate that hides itself after a break instead of shaming you
  • Local persistence - progress lives in the browser and survives closing the tab, no account needed
Engineering

Challenges & Learnings

  • Offline as a hard constraint - static export makes any accidental server dependency a build error; bundling the data and using native text-to-speech means zero network calls at runtime
  • A pure, testable core - the Leitner scheduler reads no clock and no randomness of its own; the caller injects the time, which makes every scheduling rule deterministic to test
  • Hydration-safe storage - reading local storage through useSyncExternalStore so a statically-exported page never mismatches between server and client render
  • A real state machine - the card lifecycle (introduce, prompt, reveal) is modelled so illegal transitions cannot happen, not just guarded by the UI
  • A modular course model - the scheduler knows nothing course-specific, so a second course such as JLPT is one data file plus one line, with no change to the engine

// Problem

I study for the BJT exam on the train, where there is no signal, and most flashcard apps either need a connection, fetch their audio, or drown you in settings. I wanted something that starts the moment I open it, works entirely offline, and trains the one skill the exam actually tests - understanding spoken business Japanese.

// Solution

BJT Trainer bundles its whole vocabulary into the app and speaks Japanese with the device's built-in voice, so it needs no network once loaded. A Leitner scheduler surfaces your weakest cards first, units unlock by mastery rather than by date, and a hand-written service worker caches the app shell so it even launches with no signal at all.

// What I Built

Logic

Spaced-Repetition Engine

Built the Leitner box scheduler and the mastery-gated unlocking as pure functions with no side effects - time is passed in, ordering is deterministic, and every rule is covered by unit tests. This is the part I can reason about and explain end to end.

Audio

Offline Speech

Wrapped the browser SpeechSynthesis API so Japanese plays with no fetched audio, handled the async voice-loading quirk, and added a warning when no Japanese voice is installed - because otherwise the app would read Japanese with an English voice and teach the wrong pronunciation.

UX

Goals You Can See

Designed two progress surfaces from the same data: a unit unlock ring that counts down to the next week on the study screen, and a course mastery bar on the home screen that watches every card move from box 1 to box 5 - with a pace estimate that suppresses itself after a break rather than reporting you as behind.

PWA

Installable & Offline

Wrote the service worker by hand rather than pulling a plugin: a versioned cache, cleanup of old caches on activate, a resilient install that will not fail the whole app over one asset, and a manifest so the trainer installs to the home screen and launches with no connection.

// Result

BJT Trainer is the project where I focused on engineering rigour rather than surface polish: a pure, fully tested logic core, an offline constraint enforced by the build, and a state machine that makes broken UI states impossible. It holds 192 vocabulary cards across 24 themed units and is built so a second course, such as JLPT, can be added without touching the engine.
